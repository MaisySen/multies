# Premium pass 2 (R35): depth, motion and one icon set

The web app should feel like the same family as the phone app and like a native Mac and iPhone app. This note keeps
later rounds consistent. Blue #0071E3 stays the one accent.

## Icons

- One icon module: `src/web/components/ui/icon.tsx`. Import a glyph by its semantic name, `IconInbox`,
  `IconTasks`, `IconSnooze` (the name below in PascalCase after `Icon`): `<IconInbox className="h-4 w-4" />`. Pass the
  component itself where one is expected (nav items, menus, swipe actions).
- One module per glyph (`ui/icons/`, generated by `scripts/r35-gen-icons.mjs` from `scripts/r35-icon-map.json`), two
  weights each, so a page chunk carries only the few hundred bytes of the glyphs it uses.
- Glyphs are Phosphor (MIT), the same family the phone app draws on iOS. Names shared with the phone app
  (`mobile/src/components/Icon.tsx`) use the phone app's glyph.
- Weight: regular by default; `filled` (fill weight) for the active nav item and selected states (a starred star,
  the swipe action, summary tiles).
- Sizes: 16 inline with text, 20 in rows and buttons, 24 in bars and tiles (`ICON_SIZE.sm/md/lg`). A Tailwind
  `h-4 w-4` class still wins. Colour is always `currentColor`.
- Decorative by default (`aria-hidden`); pass `aria-label` or `title` when the icon is the only label.
- Lint: `no-restricted-imports` blocks `lucide-react` and `@phosphor-icons/react` outside icon.tsx. Need a new
  glyph? Add a semantic name to `scripts/r35-icon-map.json` and run the generator; never import a glyph in a page.

## Depth

| Token | Use |
| --- | --- |
| `--shadow-e0` / `.elev-0` | flat, inside a grouped list |
| `--shadow-e1` / `.elev-1` | resting cards, summary tiles, chips, the active nav row |
| `--shadow-e2` / `.elev-2` | hover on a card, popovers |
| `--shadow-e3` / `.elev-3` | sheets, the phone drawer, dialogs |

Each shadow is a 0.5 px ring plus a tight contact shadow plus a wide soft ambient one. Dark mode swaps in a faint
white ring and deeper black, because shadows vanish on dark surfaces.

- Hairlines: `.hairline-b`, `.hairline-t`, `.hairline-r` (0.5 px, `--color-line-strong`).
- Radii: 10 px controls and tiles (`--radius-r10`), 14 px cards (`--radius-r14`), 20 px sheets (`--radius-r20`).
- Translucent chrome: `.glass` (top bar, sheets) and `.glass-sidebar`: `saturate(180%) blur(20px)` (24 px for the
  sidebar) over `--color-glass` at 72 to 78 % opacity. Where `backdrop-filter` is missing they fall back to the opaque
  surface.
- Sidebar: every section has a tinted rounded tile (22 px, 6 px radius, white glyph) like the system settings
  sidebar; the active row is filled blue with white text and the glyph switches to its fill weight.

## Motion

- Durations 150 ms (state), 200 ms (enter), 260 ms (settle). Curves: `--ease-out` for state, `--ease-spring`
  (`cubic-bezier(0.32, 0.72, 0, 1)`) for things that arrive or settle.
- Transform and opacity only. `prefers-reduced-motion` already cuts every animation to 1 ms (index.css).
- Route change: `.route-in` (6 px rise and fade, 220 ms), keyed on the section so switching items inside a section
  does not replay it.
- Press: `.pressable` scales to 0.98 on touch screens only. Focus rings are untouched.

## Swipe rows (mobile web)

`src/web/components/ui/swipe-row.tsx` (`SwipeRow` for div rows, `SwipeTr` for table rows), maths in
`src/web/lib/swipe.ts` with unit tests. Touch only, under 768 px, off in selection mode.

| Rule | Value |
| --- | --- |
| Slop before deciding | 10 px; sideways must beat vertical by 1.7x |
| Action shows (release leaves it open) | 72 px |
| Long swipe commits | 60 % of the row, at least 180 px |
| Flick commits | 0.65 px/ms past the reveal point |
| Rubber band | from 85 % of the width |
| Haptic-like cue | the action glyph bumps once (scale 1.06, 260 ms) when the commit line is crossed |

Mail: swipe left archives (moves back to Inbox in Archive), swipe right snoozes until tomorrow; both go through the
same undoable path as bulk actions, so the toast offers Undo. Tasks: swipe right marks done, swipe left opens the
task (its panel holds every other action).

## Large titles

Pages keep their own `h1.large-title` (or `h1[data-large-title]`). On phones, once it scrolls under the top bar the
bar shows the same words small and centred (`src/web/lib/large-title.ts`); the bar copy is `aria-hidden` so there is
one heading.

## Today

`/app/my-work`: the date above a large greeting, a line that says what matters, quick add chips, five summary cards
from `GET /api/counts` and My Work (unread mail, due today and overdue, next meeting with Join from 10 minutes before,
mentions, approvals), then a Focus list of the top five items, then the full sections. Empty lists use the brand
illustrations in `src/web/components/illustrations.tsx` (inbox zero, no tasks, no chat, no docs, a clear day).
